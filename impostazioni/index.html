Salvataggio dei dati

Progresso e impostazioni restano solo in questo browser. Esporta un backup per spostarli su un altro dispositivo. La chiave API non viene mai inclusa nell'export.

Azzera

Cancella i dati di una sezione. L'operazione non si può annullare: esporta prima un backup.

Correzione con AI (facoltativa)

Costi, privacy e sicurezza. Inserendo una chiave API personale, la risposta dello studente e la rubrica vengono inviate al provider scelto, che può addebitarti dei costi. La chiave resta solo nel tuo browser (di default per la sola sessione), non entra nel repository né nell'export, ed è inviata solo al provider. Una chiave usata in una pagina web è esposta a chi controlla il tuo browser: usa una chiave con limiti di spesa. Senza chiave resta attiva la correzione offline.

L'intestazione per l'accesso diretto dal browser non è documentata nelle pagine ufficiali consultate: è un'impostazione modificabile DA VERIFICARE. Se il provider blocca la chiamata (CORS) vedrai un messaggio chiaro.
